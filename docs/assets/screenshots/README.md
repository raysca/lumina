# App screenshots

Used by the top-level README and the website (`site/build.sh` copies them into
the Pages build). Every shot shows only the CC0 demo library from
[`scripts/demo-library`](../../../scripts/demo-library/), never a personal library.

- Captured on macOS from a 1440×900-point window at 2× (2880×1800), window only,
  no shadow. `search`, `smart-album` and `compare` are cropped.
- Stored as WebP (quality 82) to keep the repository small.
- `palette.webp` is not used on a page yet. It is here for launch posts.

To retake them, build the demo library, run Lumina with an isolated `HOME` so it
opens only that library, then capture the window with `screencapture -l <id> -o`.
