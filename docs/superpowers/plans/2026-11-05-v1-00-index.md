## Suggested order

1. **Plan 1 (release)** first: it needs your Apple credentials and a git
   remote, and nothing reaches users without it. It runs in parallel with
   everything else (it touches scripts/CI/plist, not app code).
2. **Bug fixes found while planning** (small, land before features):
   - Tag edits drop captions from the search index: `catalog/tags.rs` FTS
     re-insert omits the `caption` column (plan 4, Task 1).
   - `-beach` matches beach photos and misspelled filters (`is:favourite`)
     are silently dropped (plan 3, search tasks).
   - `write_sidecar` overwrites another app's `file.ext.xmp` (plan 4, Part B).
   - Startup restore overrides a view the user picked during the first scan
     (plan 2).
   - On the welcome screen ⌘K, ⌘/ and ⌘, open overlays that never paint and
     then swallow every key; Quit is missing there and during the first scan
     (plan 2, Tasks 7a/7b).
   - `make notarize` can never pass: it greps `codesign -dv`, which does not
     print the authority, and hides Gatekeeper failures with `|| true` (plan 1).
3. **Plan 2 (UX-1)**, then **plan 3 (UX-2)**: everyday feel before features.
4. **Plan 4 (metadata)**, then **plan 5 (organize)**: both change the schema
   and both extend `merge_metadata_in_tx`, so run them one after the other.
5. **Plan 6 (polish and access)** last for the full sweep, but adopt its rules
   now: new strings go through `i18n.rs`, new colors through `theme.rs`, new
   controls get a role and label.

## Conflicts between plans (resolved in review)

- **`⌘[` / `⌘]`:** plan 2 owns them (Back / Forward). Plan 4's Rotate moved
  to `R` / `⇧R`, which no keymap or other plan uses (only `⌘R`/`⇧⌘R` are
  bound).
- **Digit keys:** plain digits rate everywhere (plan 5); viewer zoom presets
  move to `⌘0/⌘1/⌘2/⌘4` with Fill on `⌘3` (plan 3 Task 2, plan 5 Task B0,
  whichever lands first does the move). No `⌘digit` is bound today.
- **Quick filters:** plan 3 Task 9 replaces the `GridFilter` dimming with
  query-token filters; plan 5's Show Picks / Show Rejected build on those and
  wait for Task 9 rather than extending `GridFilter`.
- **Schema versions:** plans 4 and 5 now say "next `SCHEMA_VERSION`
  (currently 14)"; whichever lands second renumbers. Tests assert
  `user_version == SCHEMA_VERSION`, never a literal.
- **`merge_metadata_in_tx`:** both plans test their new state (rights, edits,
  album membership, flags) through both callers (duplicate merge and
  missing-file fold); the second plan must keep the first's columns.
- **Standing rule (plan 6):** from now on new strings go through `i18n.rs`,
  new colors through `theme.rs` tokens, and new controls get a role and label.

## Review

Each plan was reviewed on 2026-11-05 by an agent that did not write it; the
changes are listed in each plan's "Review notes (2026-11-05)" section. Facts
checked by hand during review: the search-index caption bug (reproduced in
sqlite: after a tag edit a caption-only word can never be removed, and a word
in both caption and old tag stops matching), `count(*)` on the contentless
index works, the fixture clip is 2.0 s 64×48 H.264, `notarize_release.sh`
leaves a zip where `release.yml` uploads `*.zip`.

## Open decisions, by plan

The details are in each plan's last section.

- **1:** repo location and visibility; 0.2.0 vs 0.2.1; notary auth (Apple ID
  vs App Store Connect key); GitHub `release` environment; bundle id
  `com.lumina.photos`; copyright holder; oldest macOS you can test; folder
  access prompt text.
- **2:** sample library (generated, CC0 set, or none); toolbar Back/Forward;
  reopen viewer on relaunch; per-item export progress.
- **3:** toolbar Filter menu; scroll = pan when zoomed; search scope (library
  vs current album); Fill shortcut; removing the dimming filter.
- **4:** `/` as the keyword separator; skip vs merge foreign sidecars; rights
  searchable; shortcuts; per-item rights; export of edited photos; edit-a-copy
  default.
- **5:** manual album order; offline-only map vs opt-in tiles (needs product
  approval under AGENTS.md §5.4); picks in XMP; collapsing stacks in the grid;
  digit keys; slideshow video behaviour; persisted loop range; cover
  thumbnails.
- **6:** proof locale (German?) and reviewer; default appearance; viewer theme
  in light mode; accent presets; density; update check form; sidebar arrow
  keys; log tail in diagnostics.
